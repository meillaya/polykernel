SUMMA mapping on a 4×4 grid. A panels broadcast east along each row (injected at the west edge, re-emitted east by each PE); B panels broadcast south along each column (injected at the north edge); C accumulates output-stationary in each PE’s local SRAM. Ping-pong colours double-buffer A/B. Average broadcast span = P−1 = 3 hops.

Critical-Path Timeline

cycle — broadcast fill (P−1 single-cycle hops) then pipelined FMAC compute (one panel accumulate per cycle)

The critical path is broadcast fill — the first A/B panels cross the P×P grid in P−1 single-cycle hops (solid bars) — followed by pipelined compute: one FMAC panel accumulate per cycle (green, s0…ssteps−1), with the ping-pong colours A0/A1 & B0/B1 double-buffering so the next broadcast overlaps the current compute (pale bars). The playhead is swept by the inline script using the analytic cycle count; no network, no framework.
