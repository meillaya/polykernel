PE Grid & Tile Routes (A → east, B → south)

SUMMA mapping on a 4×4 grid. A panels broadcast east along each row (injected at the west edge, re-emitted east by each PE); B panels broadcast south along each column (injected at the north edge); C accumulates output-stationary in each PE’s local SRAM. Ping-pong colours double-buffer A/B. Average broadcast span = P−1 = 3 hops.
