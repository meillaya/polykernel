The critical path is broadcast fill — the first A/B panels cross the P×P grid in P−1 single-cycle hops (solid bars) — followed by pipelined compute: one FMAC panel accumulate per cycle (green, s0…ssteps−1), with the ping-pong colours A0/A1 & B0/B1 double-buffering so the next broadcast overlaps the current compute (pale bars).
